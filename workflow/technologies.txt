Sports Maze — Technology Stack
Programming Languages
TypeScript: Main programming language; type-safe game logic and frontend development.
JavaScript: Web programming fundamentals and asynchronous programming.
Frontend
React: User interface, menus, settings, navigation, and leaderboards.
Vite: Development server and build tool.
HTML5: Application structure and Canvas integration.
CSS: Styling, layouts, and animations.
Tailwind CSS: Responsive UI styling.
Game Engine and Rendering
Phaser 3: 2D game engine, rendering, sprites, animations, physics, and collision detection.
HTML5 Canvas: 2D game rendering.
Tiled: Visual tilemap and maze-level design.
Game Logic and Algorithms
Depth-First Search (DFS): Procedural maze generation.
Breadth-First Search (BFS): Shortest-path calculation in unweighted mazes.
A Pathfinding:* Intelligent enemy navigation and optimized pathfinding.
2D Arrays: Maze grid representation and collision mapping.
Graph Theory: Maze representation, traversal, and connectivity.
JSON: Level data and game configuration storage.
Backend and Real-Time Communication
Node.js: Backend JavaScript runtime.
Express.js: REST API development and backend routing.
Socket.IO: Real-time multiplayer communication and player synchronization.
Supabase: Authentication, player accounts, and online data.
PostgreSQL: Player profiles, match history, and leaderboards.
Redis: Optional caching and temporary multiplayer game-state storage.
Testing and Code Quality
Vitest: Unit testing for game logic and algorithms.
Playwright: End-to-end browser testing.
ESLint: Code quality and error detection.
Prettier: Consistent code formatting.
Networking and Security
HTTP / REST APIs: Client-server communication.
WebSockets: Persistent, bidirectional multiplayer communication.
JWT / Session Authentication: Secure player authentication.
Input Validation: Server-side validation of player actions and game data.
Development Tools
VS Code: Code editor.
Git: Version control.
GitHub: Repository hosting and collaboration.
GitHub Codespaces: Cloud development environment.
GitHub Copilot: AI coding assistance.
Deployment and DevOps
Docker: Application containerization.
Docker Compose: Local development environment.
GitHub Actions: Automated testing and CI/CD pipelines.
Vercel: Frontend deployment and hosting.
Render: Backend deployment and hosting.
